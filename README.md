# Multi-channel Audio Research Lab

This repository documents an existing multi-channel audio installation and outlines potential research and teaching projects that could make use of it.

## Existing physical setup

- 24 JBL loudspeakers suspended from the ceiling.
- Each speaker can be assigned its own audio channel.

The room layout, speaker model, control interface, microphone or receiver arrangements, and other specifications remain to be documented.

## Potential research directions

The system may support investigations into spatial audio, coordinated multi-speaker transmission, multi-agent communication, and related experimental software. These are research possibilities, not experiments already implemented.

## Documentation approach

Keep **verified capabilities of the existing installation** separate from **proposed experiments and additions**. Research questions, protocols, and software can be developed in this repository as the installation is characterized.
